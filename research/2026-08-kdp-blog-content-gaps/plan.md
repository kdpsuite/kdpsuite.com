# Plan — KDP blog content gaps (2026-08)

## Decision

Which new blog topics KDP Creator Suite should publish because tool vendors and publishing-education blogs ignore them or cover them too thinly — and because they feed this product (formatting, coloring-book conversion, templates, batch ops, royalty/trim tools).

Research only. No posts written.

## Reframe

Surface: “What blog topics is the competition ignoring?”

Real: Where is there creator demand (search, Reddit, Amazon Help, policy change) AND a coverage gap among tool blogs AND education blogs AND a defensible production/ops angle this site does not already occupy.

## Owned coverage (not “new” unless a distinct subtopic)

- Blog: all-in-one platform, formatting guide, royalty calculator, compliance requirements, low-content workflow
- Compare: BookBolt, Atticus, Vellum
- Tools: royalty calculator, trim-size checker
- Glossary: bleed, trim, gutter, DPI, ISBN, KDP Select, BISAC, KU, POD, hardcover, metadata

## Hypotheses (falsifiable)

- **H1** Tool blogs (Atticus/Vellum/BookBolt) cluster on formatting/themes/low-content interiors and skip catalog ops, rejection forensics, coloring-book print engineering, hardcover wrap math, team/batch workflows.
- **H2** Education blogs (Kindlepreneur, Reedsy, SPS) saturate ads/keywords/how-to-publish and under-serve print-failure, coloring-book Amazon specs, paperback-vs-hardcover unit economics, A+/metadata for low-content catalogs.
- **H3** 2024–2026 KDP policy/spec changes (AI disclosure, content quality / no reading experience, expanded distribution, hardcover, categories) created unanswered clusters.
- **H4** Forum failure modes (rejected PDF, spine width, coloring pages too dark, KU vs low-content) lack current dedicated competitor articles.

## Genre

Landscape + validation.

## Gap definition

A topic is ignored/missing only if: demand exists; competitor coverage is absent or thin/stale; we can uniquely cover it via product strengths; it is not already a full post on this site.

Classes: white space | thin/stale | saturated.

## Channels

1. Tool blogs: Atticus, Kindlepreneur, Vellum, BookBolt, Publisher Rocket, BookBrush, Tangent, Canva KDP, Reedsy editor, Draft2Digital
2. Education: Reedsy, SPS, Written Word Media, Jane Friedman, ALLi
3. Primary: Amazon KDP Help 2024–2026
4. Discussion: r/KDP, r/selfpublish, r/lowcontent, KDP community
5. SERP spot-checks on hypothesized gap queries
6. YouTube title saturation as a negative signal

## Opposition / adversarial queries

- “Kindlepreneur already owns this”
- “Amazon Help is the canonical answer”
- “low-content is dead / oversaturated”
- “no search volume, only Reddit anecdotes”
- “[topic] guide 2025/2026” site:kindlepreneur.com / atticus / bookbolt / reedsy

## Stop criteria

- ≥3 source types per confirmed thesis (Help/docs, competitor blog, forum)
- Named competitor corpus inventoried, not a two-site sample
- Adversarial pass completed
- No fabricated volumes or URLs

## Out of scope

Writing posts. Paid keyword APIs. Ads-only / KU-ads content with no product fit.
