# F1 — Tool blogs are product-adjacent (H1 mostly confirmed)

**Status:** Confirmed for Atticus, Vellum, Publisher Rocket, Tangent, Canva. **Partial exception:** BookBolt owns A+ for low-content and account-termination posts [27](../sources/27_bookbolt_a_plus_low_content.md); still skips print engineering. Kindlepreneur is an education site, not a thin tool blog.

**Evidence**
- Atticus: print-cost calculator, image sizing, themes ([13](../sources/13_atticus_product_docs.md)); editorial blog stalled Dec 2024, changelog active 2026
- Vellum: changelog + help, not coloring/policy editorial ([14](../sources/14_vellum_help.md))
- BookBolt: keywords, ads, coloring *niche*, A+ for low-content ([15](../sources/15_bookbolt_blog.md), [27](../sources/27_bookbolt_a_plus_low_content.md))
- They skip: ED exclusions, coloring vs low-content classification, LEM vs bleed, hardcover coloring trim trap, 3/day catalog ops, AI disclosure for image catalogs, print royalty-cliff SOP

**Triangulation:** vendor docs (13, 14) + vendor blog (15) + education sibling that still skips the same ops topics (09)

**Implication:** Do not treat Kindlepreneur as “a tool blog that ignores everything.” Treat Atticus/Vellum/BookBolt as empty on ops topics; treat Kindlepreneur as the education incumbent that covers marketing/how-to but not print forensics.
