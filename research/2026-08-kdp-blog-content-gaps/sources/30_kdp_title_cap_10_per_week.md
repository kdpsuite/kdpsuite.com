## Verbatim quotes

> "To ensure a positive experience for all authors, we limit the number of titles you can create at the same time to 10 per book format each week. If you expect to regularly create a large number of titles, please contact us to inquire about an exception."

## Notes

This page is titled Paperback Submission Guidelines; the weekly cap is in the body. Amazon Help still does **not** publish a 3-titles-per-day number. Guardian 2023 (source 16) remains the 3/day source. Any catalog-calendar post should cite Help's 10/week per format and treat 3/day as 2023 news, not current Help.
