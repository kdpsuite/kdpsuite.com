## Verbatim quotes

> "I created a softcover coloring book with dimensions 8.625 x 11.25, using Canva, which is 8.5 x 11 in reality. It consisted of 350 pages."

> "Amazon [...] rejected the hardcover version, stating that it was incompatible and asking me to check the manuscript."

Peer reply: "Hardcovers are possible ONLY in a limited set of trim sizes. If 8.5 x 11 is not on the list, then that's your problem. Note that a 350 page hardcover is going to be prohibitively expensive for a coloring book."

## Notes

Matches Kindlepreneur hardcover trim list (source 10): 8.5x11 paperback coloring default is not a hardcover trim. This pairing (8.5x11 coloring → hardcover) is a repeated failure mode with no dedicated named-competitor article.
